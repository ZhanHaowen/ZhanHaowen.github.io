## 日常更新

1. 打开编辑器，在本机修改资料。
2. 在论文条目中勾选或取消“在公开主页显示”。
3. 导出网站 HTML，将新的 `index.html` 上传并提交到仓库。
4. 等待 Pages 部署完成后刷新主页。

当前公开 5 项成果：3 篇已发表、1 篇期刊在审、1 项专著章节。WWW/S&P 会议在审稿已隐藏，公开网页、公开编辑器初始资料和公开 JSON 均不包含其记录。

## 本机完整资料与恢复显示

原浏览器的草稿保留完整 8 项记录，其中 3 项隐藏；本次升级会为旧草稿同步隐藏状态，不会删除论文或恢复以前删除的条目。隐藏后再手动勾选显示，后续打开编辑器会尊重你的选择。

`主页完整资料-含隐藏论文.json` 是单独保存在本机的完整私有备份，不在网站上传 ZIP 中。换设备时导入它，可恢复全部记录和显示选择，然后勾选希望重新展示的论文并导出新网页。编辑器的“导出私有 JSON”同样包含隐藏记录，仅供本机保存和跨设备导入；不要作为公开 `profile-backup.json` 上传。

显式 JSON 中的公开/隐藏选择会保留；旧 JSON 未指定显示方式的 WWW/S&P 在审稿默认隐藏。所有草稿和私有备份都不会自动更新线上主页。

## 公开发布文件

- `index.html`：仅包含公开内容，照片、样式和脚本内嵌。
- `editor.html`：通用本机编辑器，初始资料仅含公开记录；访客不能修改仓库。
- `profile-backup.json`：当前公开资料备份，不含隐藏记录。
- `.nojekyll`：直接发布静态文件。

电话和微信可分别编辑或清空；已完成的资料升级不会重复覆盖后续修改。不需要购买域名或云服务器，网络可达性由访问者所在地及线路决定。
